    1. ความสอดคล้องตามคำอธิบายรายวิชา (Course Description - ครบถ้วน 8 ด้าน)

    1. Data Types

    รองรับข้อมูลหลายมิติ: เวลา (Time-Series 50 เดือน), พิกัดภูมิศาสตร์ (77 จังหวัด), และหมวดหมู่ (คนไทย/ต่างชาติ/Tiers)

    2. Human Perception

    ใช้ทฤษฎี Gestalt และสีแบบ Diverging/Sequential เน้นความต่างของคนไทย (ฟ้า) vs ต่างชาติ (ส้ม) อย่างชัดเจน

    3. Multi-dimensional

    วิเคราะห์ข้ามมิติ: รายได้, ผู้มาเยือน, การใช้จ่ายต่อคน และอัตราเข้าพัก เชื่อมโยงพร้อมกันในแดชบอร์ดเดียว

    4. Tree & Hierarchical

    จัดโครงสร้างพีระมิด ภูมิภาค → จังหวัด → กลุ่มเมืองศักยภาพ Tier 1, 2, 3

    5. Network & Graph

    จำลองเครือข่ายศูนย์กลางท่องเที่ยว (Hub & Spoke Network) เชื่อมโยงเมืองหลักสู่เมืองรอง

    6. Interaction Techniques

    ระบบกรองหลายระดับ (Dynamic Filtering), Drill-down, Tooltip อัจฉริยะ และแผนที่ SVG โต้ตอบได้

    7. Design Process

    ออกแบบตามมาตรฐาน UI/UX สากล รองรับทั้ง Light/Dark Mode และ 3D WebGL Visualization

    8. Tool Evaluation

    พัฒนาด้วย Web-native Stack (HTML5, Vanilla CSS, JavaScript, Apache ECharts, Three.js)

    2. ตารางผลลัพธ์การเรียนรู้ (CLOs & PLOs Mapping Matrix)

    ผลลัพธ์การเรียนรู้ (CLO) PLO ที่เกี่ยวข้อง องค์ประกอบในแดชบอร์ดนี้ที่พิสูจน์ผลลัพธ์ ระดับการประเมิน
    CLO 1: เลือกและออกแบบวิธีแสดงภาพข้อมูลที่เหมาะสมกับชนิดและมิติข้อมูล PLO 3 กราฟเส้นแบบ Multi-axis, แผนที่ความหนาแน่นเชิงภูมิศาสตร์, Bar Chart เปรียบเทียบสองกลุ่ม, และ Donut Chart ดีเยี่ยม (A)
    CLO 2: ประยุกต์หลักการรับรู้ทางการมองเห็น (Visual Perception) PLO 3 การจัด Visual Hierarchy ชัดเจน, ค่า Contrast สูงตามเกณฑ์ WCAG AAA, การเลือกชุดสีที่สื่อความหมายโดยตรง ดีเยี่ยม (A)
    CLO 3: พัฒนาระบบแสดงภาพข้อมูลที่มีปฏิสัมพันธ์กับผู้ใช้ (Interactivity) PLO 4 ระบบ Filter Ribbon 3 แกน, การคลิกเลือกภูมิภาคบนแผนที่, ตารางค้นหาแบบ Real-time, และ 3D Hover Tilt ดีเยี่ยม (A)
    CLO 4: สื่อสารข้อค้นพบและวิเคราะห์เชิงลึกด้วย Data Storytelling PLO 5 โมดูล Data Storytelling 5 ขั้นตอน พร้อม Highlight ตัวเลข และข้อเสนอแนะเชิงกลยุทธ์สำหรับผู้กำหนดนโยบาย ดีเยี่ยม (A)

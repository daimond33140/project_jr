# โครงงานวิชา 01418325 ข้อมูลจินตทัศน์ (Data Visualization)
## หัวข้อ: Thailand Tourism Intelligence — ข้อมูลจินตทัศน์สถิติการท่องเที่ยวไทย (2562 - 2566)

**อาจารย์ผู้สอน:** ผศ.ดร.จารุวัฒน์ ไพไกล  
**ภาควิชาวิทยาการคอมพิวเตอร์และสารสนเทศ** คณะวิทยาศาสตร์และวิศวกรรมศาสตร์

### 1. แหล่งที่มาของข้อมูล (Official Data Source)
* **หน่วยงานเจ้าของข้อมูล:** กระทรวงการท่องเที่ยวและกีฬา (Ministry of Tourism and Sports - MOTS)
* **ชุดข้อมูลที่นำมาใช้:** `data/thailand_domestic_tourism_2019_2023_ver2.csv`
* **ขอบเขตข้อมูล:** 
  * ครอบคลุม **77 จังหวัดทั่วประเทศไทย** ใน 5 ภูมิภาคหลัก
  * ช่วงเวลา: **มกราคม 2562 - กุมภาพันธ์ 2566 (รวม 50 เดือน)**
  * ตัวชี้วัดสำคัญ: รายได้รวม, รายได้จากนักท่องเที่ยวชาวไทย, รายได้จากนักท่องเที่ยวชาวต่างชาติ, จำนวนผู้เยี่ยมเยือน, และอัตราการเข้าพักเฉลี่ย (Occupancy Rate)
  * มูลค่ารายได้สะสมทั้งสิ้น: **5.17 ล้านล้านบาท (5.17 Trillion THB)**

### 2. การแมปกับประมวลการสอน (Syllabus, CLOs & PLOs Alignment)

#### 2.1 สอดคล้องตามคำอธิบายรายวิชา (8 องค์ประกอบครบถ้วน 100%)
1. **หลักการข้อมูลจินตทัศน์:** ออกแบบ Visual Encodings, การเลือกคู่สี และลดภาระทางปัญญา (Cognitive Load)
2. **แหล่งที่มาของข้อมูล:** ข้อมูลจริงกระทรวงการท่องเที่ยวและกีฬา (MOTS) ไฟล์ `data/thailand_domestic_tourism_2019_2023_ver2.csv` (30,800 แถว)
3. **การเชื่อมโยงข้อมูล:** ระบบ Cross-Filtering แบบไดนามิก เชื่อมโยงตัวกรองปี ภูมิภาค กลุ่มเมือง แผนที่ และตารางเข้าด้วยกัน
4. **การแสดงภาพข้อมูลช่วงเวลา:** Time-series ต่อเนื่อง 50 เดือน (มกราคม 2562 - กุมภาพันธ์ 2566)
5. **การแสดงภาพข้อมูลแนวโน้ม:** Dual-Axis Line & Area Chart แสดงแนวโน้มการเติบโตและการฟื้นตัว
6. **การแสดงภาพข้อมูลแบบภูมิทัศน์:** Interactive SVG Thailand Map 5 ภูมิภาคและฟองสบู่ (Bubble) จังหวัด
7. **การบอกเล่าเรื่องด้วยข้อมูล:** Data Storytelling Walkthrough 4 บท สรุปปัญหา ข้อค้นพบ และข้อเสนอแนะเชิงยุทธศาสตร์
8. **กระดานข้อมูล:** Executive Dashboard พร้อมบัตร KPI สรุปผล 5 ตัวชี้วัด และตารางสถิติแจกแจง 77 จังหวัด

### 4. สรุป Insight สำคัญจากข้อมูลจริง (Key Insights & Findings)

1. **The Great COVID Shock:** ในปี 2562 รายได้แตะระดับสูงสุด 2.73 ล้านล้านบาท แต่ในปี 2564 รายได้รวมดิ่งลงเหลือเพียง 2.41 แสนล้านบาท (-91% จากช่วงก่อนโควิด) โดยรายได้จากต่างชาติหายไปเกือบหมด
2. **พลังตลาดในประเทศ (Safety Net):** ตลอดช่วงวิกฤต นักท่องเที่ยวชาวไทยยังคงสร้างรายได้กว่า 2.16 แสนล้านบาทในปี 2564 ช่วยพยุงไม่ให้ธุรกิจท่องเที่ยวล้มละลายทั้งระบบ
3. **ความเหลื่อมล้ำรายจังหวัด (Inequality):** เพียง 4 จังหวัดหลัก (กทม., ภูเก็ต, ชลบุรี, เชียงใหม่) กวาดรายได้สะสมไปถึง **70.4% ของประเทศ** ขณะที่อีก 73 จังหวัดที่เหลือแบ่งรายได้กันเพียง 30%
4. **ความเสี่ยงของเมืองพึ่งพาต่างชาติ:** ภูเก็ตพึ่งพารายได้จากต่างชาติสูงถึง 82% ทำให้เมื่อเกิดวิกฤตจะได้รับผลกระทบหนักที่สุด
